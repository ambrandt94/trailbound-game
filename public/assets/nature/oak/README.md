# Oak

Model Forge / Library output. These files are derived runtime assets. Do not hand-edit them.

The set is a `trailbound.manifest/1` oak: four glTF variants in metres, +Y up, +Z forward, origin at the ground centre. Each GLB is one `OakRoot` with two primitives. The materials are named `bark` and `foliage`. The game binds textures by those material names. `bark_oak_dark.png` is the wood pool's ironbark alternate. The other two textures are also embedded in the GLBs.
